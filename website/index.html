⚡ Sub-0.6s Batch Parse Throughput

High-performance compiler pipeline achieving ~0.045s parse times on 1MB batch files (>22 MB/s throughput) with native WebAssembly acceleration.

🌐 15 Ethiopic Dialects & Languages

First-class native script support for Amharic, Classical Ge'ez, Tigrinya, Gurage, Gojjami, Gondari, Wollo, Harari, Silt'e, Wolaytta, Gamo, Gofa, Hadiyya, Kembatta, and Afaan Oromoo.

🔄 Bidirectional Transpiler & AST Idempotency

Convert existing Python codebases into Ethiopic script with proven AST equivalence: AST(Forward(Reverse(C))) == AST(C).

🗺️ Production V3 Source Maps

RFC-compliant Base64 VLQ source maps enable step-through browser DevTools debugging and automatic runtime traceback mapping to .amh lines.

💡 Language Server Protocol (LSP)

Complete JSON-RPC 2.0 language server providing real-time diagnostics, autocompletions, hover cards, and document outlines for VS Code, Neovim, and Cursor.

📓 Google Colab & Jupyter Magic

Run %load_ext gezelang and %%gezelang in cloud notebooks with full Python namespace sharing (NumPy, PyTorch, Pandas).

ክፍለ ተማሪ:
    ስራ __init__(እኔ, ስም):
        እኔ.ስም = ስም

    ስራ አሳይ_ስም(እኔ):
        አሳይ(f'የተማሪው ስም {እኔ.ስም} ነው')
Generated Python (.py)
class ተማሪ:
    def __init__(self, ስም):
        self.ስም = ስም

    def አሳይ_ስም(self):
        print(f'የተማሪው ስም {self.ስም} ነው')

15 Supported Ethiopic Dialects & Languages

🇪🇹 አማርኛ (Amharic)

Status: Active (Standard, Gojjam, Gondar, Wollo)

Full support for all 37 mapped keywords, AST round-trip idempotency, and localized error diagnostics.

🇪🇹 ግዕዝ (Classical Ge'ez)

Status: Active

Classical syntax mapping (ግበር for def, ለእመ for if, አግብእ for return).

🇪🇹 ትግርኛ (Tigrinya)

Status: Active

Full vocabulary mapping (ስራ for def, እንተድኣ for if, መልስ for return).

🇪🇹 ጉራጊኛ & ስልጢኛ (Gurage & Silt'e)

Status: Active

Native Sebat Bet Gurage (ኤፑ, ተኾነ, አውጣ) and Silt'e language adapters.

🇪🇹 ወላይትኛ፣ ጋሞ፣ ጎፋ (Omotic Group)

Status: Active

Full dialect adapters for Wolaytta, Gamo, and Gofa (ኦሳ, ጊዲኮ, ዛራ).

🇪🇹 ሐረሪ፣ ሀዲይኛ፣ ከምባታ፣ ኦሮሞ

Status: Active

Native dialect adapters for Harari, Hadiyya, Kembatta, and Afaan Oromoo.
